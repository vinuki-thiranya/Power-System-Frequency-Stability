About / How to use

This example estimates π by sampling random points in a unit square and counting the fraction that falls inside the quarter circle: π ≈ 4 × (inside / total).

  • Set the parameters, then press Start. Pause stops the run; Reset clears it and applies new settings.
  • The estimate is shown with a 95% confidence interval. The error should shrink roughly as 1/√N.
  • The check compares the estimate with the reference value; the notebook gives the same result for the default settings.
