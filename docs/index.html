About / How to use

What this is

On 9 February 2025 a fault at one substation was cleared in about a second, yet the whole island lost power 22 seconds later. This page runs a small model of those seconds: the swing equation for the system frequency and a governor equation, solved with a fourth-order Runge-Kutta method in 10 ms steps, plus rules for rooftop-solar inverters and for the automatic load-shedding scheme. The default settings are calibrated to the seven recorded frequency values.

How to use it

  1. Press Start with the default settings. The frequency follows the record and falls below 47 Hz at about 16 s.
  2. Press Reset, change one setting, and press Start again.
  3. Pause freezes the run; Reset clears it. Moving any slider also resets.

Try this

  • Set wrongly set inverters to 0%: the frequency settles near 49.2 Hz and nothing else trips.
  • Set the battery to 40 MW: it holds the frequency above 49.5 Hz, so the first inverters never trip.
  • Set inertia to 2.0: the grid still collapses, only later. Inertia buys time; it does not close the power gap.

The settings

  • Embedded solar share: share of generation from sources inside the distribution network. About 50% on the day. More solar means fewer spinning machines and more solar on each shed feeder.
  • Wrongly set inverters: 41% of surveyed inverters were set to disconnect above the prescribed 47 Hz. 100% keeps them all as surveyed; 0% means every inverter waits until 47 Hz.
  • Fast battery: responds below 49.8 Hz and reaches full power at 49.5 Hz.
  • Inertia: multiplies the stored kinetic energy of the spinning machines.
  • Relief factor: share of each shed block that is real relief. Below 1 because shed feeders also carry rooftop solar.
  • Governor response: extra power the generators deliver. About 24 MW was delivered on the day; 230 MW was held in reserve.

Reading the outputs

  • The dashed lines mark 49.5 Hz (first inverters trip), 48.75 Hz (load shedding starts), 47.5 Hz (last stage) and 47.0 Hz (most inverters trip: collapse).
  • Survived means the frequency stopped falling above 47 Hz. A run still falling after 60 s is not a survival.
  • The reference check reruns the default settings and compares two numbers with the notebook.

Limits

One frequency for the whole island: no voltage and no network. The first solar loss was caused by a voltage dip and is put in by hand. The model is not expected to be exact below about 46 Hz, where generator protection takes over. Results for settings far from the day's conditions are indicative only.
